# Артефакты backend

Здесь хранятся документы, которые описывают продуктовые и технические решения,
но не являются частью исполняемого приложения.

```text
artifacts/
  prd/          продуктовые требования и границы функций
  adr/          принятые архитектурные решения
  designs/      технические дизайны перед реализацией
  runbooks/     инструкции по эксплуатации и восстановлению
```

Каталоги создаются по мере появления документов. Каждый документ должен содержать
статус и дату. PRD отвечает на вопрос «что и зачем строим», design — «как строим»,
ADR фиксирует отдельное принятое решение, runbook описывает эксплуатацию.
